# 群关系观察 · Nekro Agent

根据 QQ 群聊天语境生成有原话依据的**关系剧本**，支持父亲、母亲、兄弟姐妹、朋友、损友、恋人、夫妻、情妇、情夫、主人、仆人、舔狗、金主、工具人等娱乐标签。结合 @ 与引用回复统计，生成关系星图和高清 PNG。

**直接使用 Nekro Agent 原生 WebUI**：插件管理调整配置，在群聊的命令执行区运行 `relations`，图片直接显示在后台。后台执行结果不会发到 QQ 群。不再提供独立看板、登录页或插件网页。

![图片报告（全部为模拟对话）](https://raw.githubusercontent.com/JiaDodo/nekro-plugin-group-relations/main/docs/report-demo.png)

## 安装与升级

兼容目标：**Nekro Agent 2.3.3，Python 3.11/3.12，OneBot V11 / NapCat**。使用框架原生命令富媒体输出接口，无需修改主程序或前端。

```bash
cd /home/nekro/srv/nekro_agent/plugins/workdir
git clone https://github.com/JiaDodo/nekro-plugin-group-relations.git group_relations
```

在插件管理加载并启用“群关系观察”。已有安装执行 `git pull` 后重启 Nekro Agent。**从0.1升级必须重启**，使框架移除缓存的旧看板路由；原有互动数据保留。

## WebUI 使用

1. 在“插件管理 → 群关系观察 → 配置”设置模型组、关系标签和图片渲染地址。
2. 进入“设置 → 命令中心”（`/settings/commands`）的执行命令区，选中要分析的群，选择 `relations`，参数填 `7`。
3. 在原生命令输出中直接查看图片。重新赏析填 `7 refresh:true`；只看统计填 `7 contextual:false`。
4. 管理采集和历史用 `relations_manage`，无需另开网页。插件“数据管理”标签是框架 KV 管理，不是本插件 SQLite 浏览器。

## 群里使用

```text
/relations 7                         最近7天图片和聊天赏析
/relations 7 refresh:true            强制同步并重新赏析
/relations 7 contextual:false        仅统计互动，不调用模型
/my_relations 7                      自己的聊天搭子和相关角色梗
/relations_optout                    退出本群统计、清理插件个人互动记录
/relations_optin                     重新加入统计
```

别名：`/群关系图`、`/群关系周报`、`/群关系赏析`、`/我的群关系`、`/退出关系统计`、`/加入关系统计`。周期1–30天。也可以说“赏析本群关系”“看看谁是谁的爹”“生成主仆和CP关系图”，由 Agent 调用当前群工具。

管理员命令（WebUI管理员或框架超级用户）：

```text
relations_manage status             查看当前群采集状态
relations_manage sync days:7        补齐历史并清除赏析缓存
relations_manage pause              暂停采集和聊天赏析
relations_manage resume             恢复采集
relations_manage clear              清空本群插件记录，旧历史不再回填
```

个人退出/加入必须由本人在 QQ 群执行，WebUI 管理账号不等于 QQ 身份。

## 聊天赏析

- 读取**当前群、所选周期、主程序已经保存**的聊天正文。结合时间均匀抽样与关系词附近对话，默认最多360条、每条240字。不会逐条自动调用模型。
- 模型结合称呼、上下文接话、认亲、调情、互损、使唤等返回双方成员ID、标签、理由、消息证据ID，再核验成员、原话来源、双方关联和标签支持。无法验证就不展示。
- 方向表示**前者扮演标签角色**：乙喊甲“爸爸”，写成“甲 → 乙：父亲”。标签直接使用关系名称。互相接梗标“双向接梗”，单方称呼标“单方喊话”。
- 可以放开玩亲属梗、CP梗、情妇梗、主仆梗。恋人/夫妻/主仆需相应称呼语境；情妇/情夫需原话出现该称呼。关系是聊天剧本，不认定现实亲属、恋爱、性关系或出轨。
- 报告附原话、日期、样本数、赏析时间；不足就留空，不强配对。抽样、截断、模型误读仍可能遗漏或理解错角色方向，原话可核对。
- 赏析缓存30分钟，互动统计独立更新。`refresh:true` 强制重新赏析，调整模型/标签/样本配置使用新缓存。命令键值参数使用冒号。

DeepSeek 官方接口使用非思考模式和 JSON 输出，避免长群聊样本耗尽输出预算却没有报告；参数依据[官方思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。其他模型接口使用默认模式。

## 图片渲染

自托管 **browserless Chromium** `/screenshot`，默认 `http://nekro_html2img:3000`。容器需与 Nekro Agent 网络互通，安装 Noto Sans CJK 等中文字体。

统计与赏析 → SVG + 自包含HTML报告 → 紧凑PNG。左侧关系图、右侧聊天赏析，两张卡片横向拼成一张图，宽1480像素、1倍密度，避免纵向长图。蓝线表示 @ / 引用回复，粉色虚线表示赏析关系；卡片列出方向、理由和原话节选（较长内容压缩展示），文字报告保留更多依据。通过框架 `CommandOutputSegment` 返回图片，框架负责后台显示或群消息发送；渲染失败回退文字。无需AI绘图服务。

0.3版将概览限制为12位成员、最多14条主要连线，固定头像和昵称位置；连线直接标注父亲、损友等关系名称，方向与原话见右侧卡片。模型内部 U1/U2 代号在理由、原话、总结中统一还原为头像昵称，重名附账号末四位。QQ头像按需获取并内嵌到图片，缓存3天；头像获取失败显示昵称首字。排版与头像昵称展示参考了 [miuzhaii/nekro-plugin-group-analysis](https://github.com/miuzhaii/nekro-plugin-group-analysis)，本插件渲染实现独立编写。

0.3.2使用按连接关系分布的成员布局，中心成员居中；连线为直线或轻微弧线，标签仅沿线滑动，不会把连线拉成折角。昵称底板按实际文字宽度计算。复杂关系可以有交叉，概览不承诺完全无交叉。

| 单日单向互动计分上限 | 20 | 控制刷屏影响，实际次数完整展示 |
| 启用聊天赏析 | 开 | 请求时发送抽样正文和昵称到所选模型 |
| 聊天赏析模型组 | 空 | 使用系统主聊天模型组 |
| 聊天赏析样本条数 | 360 | 20–1000条 |
| 单条赏析文本字数上限 | 240 | 80–500字 |

| 渲染超时秒数 | 60 | PNG渲染超时 |

## 数据与统计

插件 SQLite (`relations.sqlite3`) 保存群、成员、时间、@对象、引用ID，不复制完整聊天正文。赏析按群读取主程序历史，**交给配置的模型服务**；原话片段存在内存报告缓存和图片中。插件 PNG 缓存约24小时清理。原生 WebUI 产生的附件副本、命令输出历史由 Nekro Agent 管理。

生成图片时请求 QQ 公共头像接口，最多获取本次显示的64位成员头像，头像二进制保存在 `avatar_cache`，3天后使用时刷新。退出、暂停或清空时同时清除插件图片与头像缓存。

退出后删除插件本人记录、入向@和已解析引用作者；抽样排除退出者和明确指向退出者的消息，清除赏析缓存。清空/暂停不删除主程序历史或已发送/下载的报告。清空时间边界阻止旧历史重新导入；重新加入可能再导入主程序仍保留的记录。

同一消息对同一人的@和引用只算一次，优先引用；排除自己、全体、机器人、退出者，跨群引用不计入。指数按引用权重3、@权重2、每日上限、双方发言量、双向程度和互动天数排序，是排序指标而非关系概率。相邻发言不增加统计互动次数；聊天赏析可识别有原话依据的上下文角色。

## 开发

```bash
python -m pip install httpx
python -m unittest discover -s tests -v
python scripts/demo.py /tmp/group-relations-demo
python scripts/layout_samples.py /tmp/group-relations-layout --endpoint http://nekro_html2img:3000
```

测试覆盖统计、群隔离、退出与清空、抽样上限、证据核验、虚构ID/无依据标签过滤、模型输出转义和赏析缓存。模拟脚本仅生成虚构成员与对话。

连线样例脚本生成6组可重复的虚构数据：5人交叉关系、12人普通关系网、54人密集群聊、12人单人中心、8人分组重名、空数据。输出 `index.html` 检查页及各组 PNG、SVG、HTML、JSON；省略 `--endpoint` 可离线生成除PNG之外的文件，不调用聊天模型。自动检查包含头像昵称间距、画布边界、中心成员位置、曲线端点与弯曲幅度、标签位于对应曲线上、样例标签不遮挡头像昵称、密集群聊保留完整卡片。

图片故障检查渲染地址、令牌、容器网络、中文字体。赏析失败检查聊天模型组，失败仍显示统计。后台没有命令执行功能时，请升级到支持富媒体命令输出的 Nekro Agent 版本。
